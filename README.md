# App Perpustakaan

Sistem Perpustakaan Digital Kampus untuk mengelola buku, anggota, dan peminjaman.

## Cara Menjalankan
1. git clone https://github.com/Refido-dev/app-perpustakaan.git
2. composer install dan npm install
3. cp .env.example .env, lalu php artisan key:generate
4. Buat database db_perpustakaan, sesuaikan DB_USERNAME dan DB_PASSWORD di .env
5. php artisan serve
